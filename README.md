# プラレール シールメーカー

プラレール用の**方向幕（行先表示）などの小さなシール**を、原寸で印刷できる PNG / PDF として書き出す Web アプリです。
ブラウザだけで動き、サーバーもビルドも不要です（GitHub Pages でそのまま公開できます）。

想定用途: 近鉄 1A系 / 8A系 のように、キットに側面の行先表示シールが付属していない車両の自作。

## できること

- **行先表示（方向幕 / LED）**: 種別・行先・駅ナンバー（E01 など）の 3 パーツを個別に表示 / 非表示。種別・行先それぞれに枠付き / 塗りつぶし（色・文字色・角丸）、行先の英字は下（2 段）または横に配置。フォント・LED ドット風表示に対応
- **前照灯・尾灯**: ケース（台座）の中に、ランプの「段」を上から積む。段ごとにランプの色・形・大きさ・見た目・寄せ方を持つので、
  「2 灯の下に尾灯ライン」のような最近の車両の形も作れます。
  - ランプ: 色ごとに追加・並べ替え（1 段に最大 6 灯、最大 4 段）。前照灯 / LED / 黄 / 尾灯 / 標識灯の色をまとめて選べる
  - 形は丸・楕円 / 角型 / 帯。見た目は「光って見える」「レンズ風」「LED の粒」「消灯」「ベタ塗り」。銀や黒の縁、寄せ方（均等・中央・左・右）
  - ケースの形は長方形・台形・片側が斜め・平行四辺形。全体を回転させて斜めに配置できる（シールに収まるよう自動で縮める）
  - 前照灯と尾灯が並ぶ形は「左右ペア」にすると、1 組で鏡写しの 2 枚を並べる（斜めの向きも反転）
- **プリセット**: 「プリセットから選ぶ」でカテゴリごとにサムネイル付きで選べます。
  行先表示（8）、前照灯・尾灯の基本の形（7）・組み合わせ・2 段（6）・斜め・変形（4）、帯・ライン（1）、文字・車番（2）
- **文字シール**: 車番などの任意テキスト（複数行可）
- **背景**: 単色のほか、任意の本数・幅の割合のストライプ（横縞 / 縦縞）。各帯は 2 色のグラデーション（上→下 / 左→右）にもできるので、車両の帯（ライン）シールも作れます
- **画像シール**: 手持ちの画像を指定サイズに収める（全体を収める / 枠いっぱい）。ロゴ向けの簡易編集つき
  - 背景の透明化（外周からつながった部分だけ / 画像全体の同じ色、許容範囲、輪郭のなじませ）
  - 色の置き換え（スポイトで元画像から色を拾い、新しい色へ。何組でも追加可）
  - 単色化（シルエット）、透明な余白の切り詰め、高さを画像の縦横比に合わせる
  - 元画像は変更せず編集内容だけを保存するので、いつでも戻せます
- 寸法は **0.1 mm 単位**で指定。枚数を指定すればシートに自動で並べます
- **塗り足し**（背景色のはみ出し）と **トンボ / 枠線** で切り抜きしやすく
- **コンビニ印刷の縮小を打ち消す事前拡大**と、**ものさし印刷によるキャリブレーション**
- **色補正**: 色見本シートを実際に印刷し、その写真（スキャン）から「意図した色と印刷された色の差」を読み取って、書き出しの色を逆向きに調整
- PNG（dpi 情報入り）書き出し、ブラウザ印刷（PDF 保存）、プロジェクトの JSON 保存 / 読み込み、ブラウザへの自動保存
- スマートフォンでは画面下の「編集 / プレビュー」で切り替え（選択は記憶されます）

## コンビニ（ローソン・ファミマ・ミニストップ）で印刷する

シャープ製マルチコピー機の「シールプリント」を使います。**重要な制約**が 2 つあります。

1. **シール紙は L判 (89×127) / スクエア (127×127) / 2L判 (127×178) の 3 サイズのみ**。A4 のシール紙は用意されていません。
   A4 シール台紙を使いたい場合は家庭用プリンタ（下記）で印刷してください。
2. 写真プリント扱いのため、**「フチあり」を選ぶと全体が約 3.5〜4% 縮小**され、
   **「フチなし」を選ぶと拡大されて周囲が切れます**。原寸が重要な方向幕では致命的なので、このアプリは
   書き出し時にあらかじめ逆方向に拡大／縮小しています（「サイズ補正」）。
   既定値は L判 103.6%（実機で 108% 書き出しの 50 mm が 52.1 mm に印刷された実測から算出）、2L判 104%（Gigamix Online の実測）、
   スクエア 104%（推定）です。

手順:

1. 用紙で L判 / スクエア / 2L判 を選び、印刷方法「コンビニ シールプリント（フチあり）」にする（推奨）
2. シールを追加・編集して「PNG を保存」
3. [ネットワークプリント](https://networkprint.ne.jp/) に **写真プリント** として登録（会員登録不要）
4. 店頭で「シール紙」→ 選んだサイズ →「**フチあり**」で印刷（L判 200 円、スクエア 250 円、2L判 300 円）
5. 初回は「ものさし（50 mm）」を入れて印刷し、実測値を「キャリブレーション」に入力すると、機体ごとの差も補正できます

## 色が思ったとおりに出ないとき（色補正）

コンビニのシール紙は、画面より暗く・くすんで、色味も偏って出ることがあります。実際の印刷結果から補正を作れます。

1. 「用紙と印刷方法」の「色見本から補正を作る」を開き、**色見本シートを保存**して、シールと同じ店・同じ方法（フチありなど）で印刷します。
   色見本には 48 色のマス（番号つき）と 4 隅のマークが入っています
2. 読み取り方を選びます
   - **目で見て合わせる**（既定）: 印刷した色見本を画面の横に並べ、「印刷の ○ 番のマス」に一番近い色を 3×3 の候補から選びます。
     真ん中を選ぶとより細かい候補に進み、12 マスを 1 マスあたり 5 回ほどの選択で合わせます。
     画面の明るさは固定し、ナイトモードや True Tone などは切ってください。デザインと同じ画面で合わせると、その画面で見た色に近づきます
   - **写真・スキャンで読み取る**: 色見本をスキャンするか真上から撮影して取り込み、4 隅のマークを 1 → 4 の順にクリックします（近くのマークの中心に自動で合います）
3. 印刷のずれ（平均 ΔE）と補正後の推定が表示されるので、「この補正を使う」を押します

以後の PNG 書き出しと印刷に補正がかかります（紙の白はそのまま）。強さ（%）とプレビューへの反映は後から切り替えられます。
仕組みは、灰色の段階から各色の階調カーブを作り、残りの色で色のずれ（色かぶり・彩度）を最小二乗で当てはめるものです。
写真の場合は、色見本の白いマス（紙の色）を基準に明るさと色かぶりを打ち消します。
目で合わせる場合は、紙の白を画面の白、印刷の黒を画面の黒とみなします。

## 家庭用プリンタ / A4 シール台紙で印刷する

1. 用紙で A4（または台紙の実寸）を選ぶと、印刷方法が「家庭用プリンタ」（補正 100%）になります
2. 「印刷 / PDF」を押し、印刷ダイアログで **倍率 100%（「ページに合わせる」を外す）**、余白なしで印刷します
3. ずれる場合はものさしを印刷してキャリブレーションしてください

## 開発

```sh
npm install        # http-server と playwright（テスト用）
npm start          # http://localhost:8080
npm test           # Playwright によるスモークテスト + アクセシビリティテスト
npm run test:a11y  # アクセシビリティテストのみ
```

テストは 2 本あります。

- `tests/smoke.mjs` … 書き出しピクセル数・配置・キャリブレーション・画像編集・色補正・自動保存
  （色補正は `tests/colorsim.mjs` の「暗く・くすんで青寄りに出るプリンタ」と「傾けて撮った写真」、
  および「見た目どおりに一番近い候補を選ぶ人」で検証）
- `tests/dist.mjs` … 配信物の検証。ビルドスクリプトでバージョンが付き、dist 版がそのまま起動すること
- `tests/a11y.mjs` … キーボード操作。すべての操作要素にアクセシブルネームがあること、Tab 順が画面の並びどおりであること、
  値を変えて Tab しても次の欄へ進むこと（フォーム再構築でフォーカスを失わない）、シール一覧が矢印キー / Delete / Ctrl+D / Alt+↑↓ で操作できること、
  色見本がグループで 1 つの Tab 停止であること、ダイアログを閉じたときフォーカスが戻ること

- `index.html` … 画面
- `js/model.js` … データモデル・用紙 / フォント / プリセット定義
- `js/layout.js` … シート上の自動配置（棚詰め）
- `js/render.js` … キャンバス描画（プレビューと書き出しで共通、単位は mm）
- `js/export.js` … PNG（pHYs で dpi 埋め込み）・印刷
- `js/imageedit.js` … 画像の簡易編集（背景の透明化・色の置き換え・単色化・切り詰め）
- `js/colorcal.js` … 色補正の計算（色見本の描画、写真の読み取り、補正モデルの当てはめと適用）
- `js/colorui.js` … 色補正の画面（用紙欄の設定と、色見本の写真から補正を作るダイアログ）
- `js/storage.js` … localStorage / JSON 入出力
- `js/app.js` … UI（再描画は次のタスクに遅延し、`data-key` でフォーカスを復元する）

### GitHub Pages への公開

公開 URL: https://dairappa.github.io/plarail_seal/

`.github/workflows/pages.yml` が、既定ブランチ（`main`）への push のたびに自動デプロイします。
ほかのブランチへの push でもワークフローは起動しますが、デプロイはスキップされます。
作業はブランチで行い、`main` に取り込んだ時点で公開されます。

リポジトリの Settings → Pages の **Source は「GitHub Actions」** にしておく必要があります。
Actions タブの「Deploy to GitHub Pages」から、`main` を選んで手動で再実行することもできます。

配信物は `scripts/build-dist.sh` が `dist/` に集めます（`index.html`, `css/`, `js/`, `.nojekyll`）。
このとき CSS / JS の参照とモジュール間の import にコミット SHA のバージョン（`?v=xxxxxxxx`）を付けます。
GitHub Pages は静的ファイルを 10 分キャッシュするので、これがないと更新直後に「HTML は新しいのに CSS / JS が古い」状態になります。
相対パスだけで構成しているので、`/plarail_seal/` のようなサブパス配下でも動きます。

## 注意

- シールの寸法は必ずキット側を実測して入力してください。既定値（10×2.5 mm など）は仮の値です
- 近鉄の種別色や英字表記のプリセットは目安です。実車の写真に合わせて調整してください
- シール紙を人体に貼ること、塗装の剥がれやすい面への貼付はメーカーが禁止しています
