プラレール シールメーカー

1. 用紙と印刷方法

印刷結果からサイズ補正を求める（キャリブレーション）

「ものさし」を入れて試し刷りし、印刷された 50 mm の目盛りを実測して入力すると、補正 % を自動で更新します。

2. 配置

塗り足し＝シールの外側に背景色をはみ出させる幅。切り抜きが多少ずれても白フチが出にくくなります。

3. シール

    ↑↓ で選択、Delete で削除、Alt+↑↓ で並べ替え、Ctrl+D で複製

    4. 編集:

    100%

    使い方

    コンビニ（ローソン・ファミマ・ミニストップ）で印刷する

    1. 用紙で L判 / スクエア / 2L判 を選び、印刷方法を「コンビニ シールプリント（フチあり）」にします。
      ※シャープ製マルチコピー機のシール紙はこの 3 サイズのみです。A4 のシール紙はありません。
    2. シールを追加・編集し、「PNG を保存」でファイルを保存します。
    3. ネットワークプリント（会員登録不要）に 写真プリント として登録し、店頭で「シール紙」「L判など選んだサイズ」「フチあり」を選んで印刷します。
    4. 「フチあり」で印刷すると全体が約 3.5〜4% 縮小されるため、このアプリは書き出し時にあらかじめ拡大しています（L判 103.6% は実機での実測値）。 機体差もあるので、初回は「ものさし」を入れて試し刷りし、実測値からサイズ補正を求めると確実です。

    家庭用プリンタ / A4 シール台紙で印刷する

    1. 用紙で A4（または台紙の実寸）を選び、印刷方法を「家庭用プリンタ」にします。
    2. 「印刷 / PDF」を押し、印刷ダイアログで 倍率 100%（ページに合わせない）、余白なしに設定して印刷します。

    ヒント

    • シールの寸法はキット側の窓や凹みを実測して入力してください。塗り足しを 0.3 mm ほど付けておくと、切り抜きが少しずれても白いフチが出ません。
    • LED 表示は「LED ドット」をオンにすると点灯風の見た目になります。小さなシールでは無効の方が読みやすいこともあります。
    • プロジェクトはブラウザに自動保存されます。別の端末に持ち運ぶときは「プロジェクト保存」で JSON を書き出してください。
